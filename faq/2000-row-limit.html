Salesforceのレポートが2,000件(2,000行)で切れる理由と、全件を取る方法

Salesforceのレポートが2,000行で切れるのは、レポートの実行画面が2,000行までしか表示せず、外部ツールがレポートを読むときに使うレポートAPIも先頭2,000行までしか返さない仕様だからです[1][3]。データが欠けているわけではありません。全件が欲しいときは、エクスポートで「詳細のみ」のCSVを選べば行数の上限なしでファイルに出せます[2]。スプレッドシートへ定期的に取り込みたい場合は、SOQLを書いて取るか、2,000件ずつ区切って取るツールを使います。

2,000行を超えるレポートを開くと、画面には「このレポートには、最大表示数 (最大 2,000 行) を超える結果があります」と表示されます[8]。このページでは、2,000行の上限がかかる方法とかからない方法を分けて並べ、無料で全件を取る方法から順に説明します。

2,000行の上限がかかる方法・かからない方法

件数はSalesforce・Google・Microsoftの公式ページに書かれている値です。

方法取れる件数2,000行で切れるか
レポートの実行画面2,000行まで表示[1]切れる
レポートAPI(Reports and Dashboards REST API)先頭2,000行[3]切れる
Excel・Power BIの「Salesforce Reports」コネクタ2,000行(Salesforce側の制限と明記)[4]切れる
エクスポート「フォーマット済みレポート」のマトリックス形式2,000行[1]切れる
Google純正 Salesforce Connector のレポート取り込みGoogleのヘルプに記載なし[5]止まる・失敗するという報告あり[6][7]
エクスポート「詳細のみ」CSV・XLS上限なし(10分でタイムアウト)[2]切れない
エクスポート「詳細のみ」XLSX10万行・100列[2]切れない
エクスポート「フォーマット済みレポート」の表形式・サマリー形式10万行・100列[2]切れない
レポート購読のファイル添付(定期メール)1万5千行・30列・3MB[1][9]切れない
Data Loader・Salesforce CLI・REST API・Bulk API 2.0(SOQLで取得)REST APIは1回2,000件ずつ、続きを取れば全件[10]。Bulk API 2.0は総件数の上限記載なし[11]切れない(SOQLが必要)

2026年7月からは、有償組織(本番・Sandbox)で画面からエクスポートするたびに、ステップアップ認証(追加のMFA)を求められることがあります[12]。詳しくは「ステップアップ認証・MFA必須化の後もレポートの自動連携は動くか」にまとめました。

無料で全件を取る方法

  1. 1回だけ欲しい: レポートの「エクスポート」で「詳細のみ」のCSVを選びます。10分でタイムアウトするほど大きいレポートは、条件で分けて何回かに分けます[1][2]。
  2. 毎週・毎月メールで届けばいい: レポート購読でファイルを添付します。1万5千行・30列・3MBまでで、超えた分は切り捨てです。Lightningのみで、管理者が機能を有効にする必要があり、公式ヘルプ上はベータ扱いです[1][9]。
  3. SOQLを書ける人がいる: Data Loaderのコマンドライン版、Salesforce CLI、REST APIやBulk API 2.0を呼ぶ自作スクリプトで、全件を定期的に取れます[10][11]。レポートではなく、オブジェクトと項目と条件をSOQLで指定し直すことになります。
  4. オブジェクト単位のバックアップでいい: 設定の「データエクスポート」で、オブジェクトごとのCSVをZIPで受け取れます。Enterprise以上は週1回、Professional・Developerは29日ごとです[13]。

Googleスプレッドシートに自動で取り込みたい場合

Google純正の Salesforce Connector は、レポートの取り込みとSOQL・クエリビルダーでの取り込みに対応し、4・8・24時間ごとの自動更新を選べます[5]。Googleのヘルプに行数の上限は書かれていませんが、レポート取り込みについては「2,000件以上の場合インポートができず、ヘッダだけ出力された」という2023年の投稿[6]や、2026年7月に「2,000行を超えるレポートの取り込みがステップアップ認証で失敗する」という投稿[7]があります。SOQLでの取り込みも、2022年に「1万2千行で止まった」という投稿があり[14]、上限なしとは言い切れません。

Google Apps Scriptで自作する場合は、1回の実行が6分まで、外部への取得は1日2万回(Google Workspaceは10万回)までという制限があります[15]。スプレッドシート1ファイルのセル数は1,000万までです[16]。

純正コネクタとReportZenの違いは「Google純正のSalesforce Connector(旧 Data Connector for Salesforce)との違い」で表にしています。

ReportZenの取り方と、実測した件数

ReportZenは、レポートAPIに「レコードIDが前回の最後のIDより大きい」という条件を足しながら、2,000件ずつ繰り返し取得します。レポートの項目・条件はそのまま使うので、SOQLは書きません。行数の上限は設けていません。

2026年9月17日に Salesforce Developer Edition で試したところ、2,354件のレポートを全件取得できました。ただし Developer Edition はデータ容量が5MBで、入れられるのは約2,500件です[17]。2,354件は2,000行の壁を越えたことの確認で、上限を測った値ではありません。

対応しているのは表形式のレポートで、レコードIDの列(取引先IDなど)が入っている必要があります。集計形式・マトリックス形式には対応していません。

ReportZen でできること

  • Salesforceのレポートを、SOQLを書かずにそのままGoogleスプレッドシートへ取り込む
  • 2,000件ずつ自動で繰り返し取得して、全件を並べる(ライセンス)
  • 1日1回、毎朝の自動更新(ライセンス)
  • インストールは無料。2,000件までの取得とCSVファイルの取り込みはライセンスなしで使えます
Google Workspace Marketplace で入手

接続には、Salesforceの管理者が接続アプリケーションを1回作る必要があります(手順)。
