Why Salesforce reports stop at 2,000 rows, and how to get all rows

Salesforce reports stop at 2,000 rows because the report view displays up to 2,000 rows, and the Reports REST API that external tools use returns only the first 2,000 rows[1][3]. Your data is not missing. To get every row once, export the report as Details Only in CSV format, which has no row limit[2]. To load all rows into a spreadsheet on a schedule, either query with SOQL or use a tool that fetches the report in 2,000-row pages.

When a report has more than 2,000 rows, Salesforce shows a notice that the results exceed the 2,000-row display maximum (in the Japanese UI: 「このレポートには、最大表示数 (最大 2,000 行) を超える結果があります」)[8]. This page lists where the 2,000-row limit applies and where it does not.

Since July 2026, paid production and sandbox orgs may require step-up authentication (an extra MFA check) each time a user exports a report from the UI[12]. See Do report integrations keep working after step-up authentication and MFA enforcement?

Free ways to get all rows

  1. Once: Export as Details Only, CSV. If the export times out after 10 minutes, split the report by a filter[1][2].
  2. By email on a schedule: Subscribe to the report with a file attachment. Up to 15,000 rows, 30 columns and 3 MB; the rest is cut off. Lightning only, must be enabled by an admin, labeled beta[1][9].
  3. If someone can write SOQL: Data Loader command line, Salesforce CLI, or a script calling the REST API or Bulk API 2.0[10][11]. You rewrite the report as a query on objects, fields and filters.
  4. Object-level backup: Setup > Data Export gives zipped CSVs per object, weekly on Enterprise and above, every 29 days on Professional and Developer[13].

Loading reports into Google Sheets automatically

Google's Salesforce Connector imports reports or SOQL / query builder results and refreshes every 4, 8 or 24 hours[5]. Google's help does not state a row limit. Users have posted that report imports over 2,000 rows returned only headers (2023)[6] and that they fail due to step-up authentication (July 2026)[7]. A 2022 post also reports SOQL imports stopping at 12,000 rows[14].

If you build your own with Google Apps Script, one execution is limited to 6 minutes and URL fetches to 20,000 per day (100,000 on Google Workspace)[15]. A Google Sheets file holds up to 10 million cells[16].

How ReportZen fetches, and what we measured

ReportZen calls the Reports API repeatedly, adding a filter "record ID greater than the last ID fetched", 2,000 rows at a time. It uses the report's own columns and filters, so no SOQL is needed. There is no row cap.

On 2026-09-17 we fetched all 2,354 rows of a report in a Salesforce Developer Edition org. Developer Edition has 5 MB of data storage, about 2,500 records[17], so 2,354 rows shows the 2,000-row wall was passed. It is not an upper limit.

Supported: tabular reports that include a record ID column (e.g. Account ID). Summary and matrix reports are not supported.

What ReportZen does
