Privacy Policy

Last updated: September 23, 2026 — 日本語版はこちら

Summary

SheetPeek (the "Add-on") is a Google Sheets add-on that shows the values referenced by the formula in the selected cell. All processing happens inside the spreadsheet the user has open. The developer does not collect, store, or receive any Google user data, and has no way to access it.

1. Data Accessed

ScopeGoogle user data accessed
spreadsheets.currentonlyThe contents of the spreadsheet the user currently has open: the formula in the selected cell, and the values and header rows of the ranges that formula refers to. Other spreadsheets and Google Drive files cannot be accessed.
script.container.uiNo user data. Used only to display the Add-on's sidebar inside the spreadsheet.
userinfo.email, userinfo.profileRequested automatically by Google for add-on installation. The Add-on's code does not read or use the user's email address or profile.

2. Data Usage

  • The data above is used for one purpose only: to display, in the sidebar on the user's own screen, the values that the selected formula refers to.
  • The Add-on only reads data, with one exception: when the user chooses the menu item "試し用のシートを作る" (Create sample sheets), it adds demo sheets to the open file. It never overwrites or deletes the user's existing sheets.
  • Google user data is not used for advertising, is not sold, and is not used to develop, improve, or train generalized or non-personalized AI/ML models.

3. Data Sharing

Google user data is not shared, transferred, or disclosed to anyone, including the developer. The Add-on does not connect to any external server, contains no analytics or tracking code, and uses no third-party services.

4. Data Protection

  • The Add-on runs on Google Apps Script within the user's own Google account. The developer operates no servers or databases, so no data is ever transmitted outside Google.
  • Access is limited to the currently open file by the narrowest available scope (spreadsheets.currentonly), rather than a Drive-wide scope.
  • If a formula uses IMPORTRANGE, the Add-on does not open the linked file; it only shows that the range is in another file.

5. Data Retention and Deletion

  • No Google user data is retained. Values are held in memory only while the sidebar displays them, and disappear when the sidebar is closed. Nothing is saved by the developer, so the retention period is zero.
  • Sample sheets created from the menu are part of the user's own file. The user can delete them at any time like any other sheet.
  • Users can revoke the Add-on's access at any time from their Google Account (myaccount.google.com/permissions) or by uninstalling it. To ask about your data, contact us at the address below.

Limited Use

SheetPeek's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Website Analytics

Separately from the Add-on, this website (getreportzen.com) uses Google Analytics with cookies to count page views and referrers anonymously. This does not involve any Google user data from the Add-on. You can stop it by disabling cookies in your browser.

プライバシーポリシー

最終更新日: 2026年9月23日

基本方針

SheetPeek(以下「本アドオン」)は、選択したセルの数式が参照している値を表示するGoogleスプレッドシートのアドオンです。処理は利用者が開いているスプレッドシートの中だけで完結します。開発者はGoogleユーザーデータを収集・保存・受信せず、アクセスする手段も持ちません。

1. アクセスするデータ(Data Accessed)

権限アクセスするGoogleユーザーデータ
spreadsheets.currentonly開いているスプレッドシートの内容(選択中のセルの数式と、その数式が参照している範囲の値・見出し行)。他のスプレッドシートやGoogleドライブのファイルにはアクセスできません。
script.container.uiユーザーデータはありません。サイドバーを画面に出すためだけに使います。
userinfo.email・userinfo.profileアドオンのインストール時にGoogleが自動で要求するものです。本アドオンのコードはメールアドレスやプロフィールを読み取らず、使用しません。

2. データの使い方(Data Usage)

  • 上記のデータは、選択した数式の参照先の値を利用者本人の画面(サイドバー)に表示する目的にのみ使います。
  • 基本は読み取りのみです。例外として、メニューの「試し用のシートを作る」を選んだときだけ、開いているファイルに試し用のシートを追加します。既存のシートを上書き・削除することはありません。
  • Googleユーザーデータを広告に使うこと、販売すること、汎用のAI/機械学習モデルの開発・改良・学習に使うことはありません。

3. 第三者への提供(Data Sharing)

Googleユーザーデータを、開発者を含む誰にも提供・移転・開示しません。本アドオンは外部のサーバーに接続せず、解析やトラッキングのコードも、第三者のサービスも使っていません。

4. データの保護(Data Protection)

  • 本アドオンは利用者自身のGoogleアカウント内のGoogle Apps Script上で動きます。開発者が運用するサーバーやデータベースはなく、データがGoogleの外に送られることはありません。
  • アクセス範囲は、ドライブ全体ではなく「開いているファイルだけ」に限られる最小の権限(spreadsheets.currentonly)にしています。
  • 数式に IMPORTRANGE があっても、リンク先のファイルは開きません。「別ファイルなので読めません」と表示するだけです。

5. 保存期間と削除(Data Retention and Deletion)

  • Googleユーザーデータは保存しません。値はサイドバーに表示している間だけメモリ上にあり、閉じると消えます。開発者側には何も残らないため、保存期間はゼロです。
  • メニューから作った試し用のシートは利用者のファイルの一部です。ほかのシートと同じように、いつでも削除できます。
  • 本アドオンのアクセス権は、Googleアカウントの設定(myaccount.google.com/permissions)またはアンインストールで、いつでも取り消せます。データについてのお問い合わせは下記までご連絡ください。

限定的使用(Limited Use)

本アドオンによるGoogle APIから受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に従います。
