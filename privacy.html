プライバシーポリシー

最終更新日: 2026年8月24日

基本方針

ReportZen(以下「本アドオン」)は、利用者のデータを収集・保存・送信しません。本アドオンの処理はすべて、利用者自身のGoogleアカウントとSalesforce組織の間で完結します。開発者は利用者のデータにアクセスする手段を持ちません。

本アドオンがアクセスする情報と目的

アクセス対象目的
Googleスプレッドシート(spreadsheets権限)取得したレポートデータを利用者のシートに書き込むため
外部サービスへの接続(external_request権限)利用者が初期設定で指定した、利用者自身のSalesforceドメインに接続するため。それ以外の外部サービスには一切接続しません
トリガー管理(scriptapp権限)利用者が有効化した場合のみ、毎日の自動更新を予約するため
ダイアログ表示(container.ui権限)設定画面・CSV取り込み画面を表示するため

保存される情報

  • Salesforce接続情報(接続先URL・コンシューマ鍵・コンシューマの秘密)およびライセンスキーは、Google Apps Scriptのユーザープロパティ(利用者のGoogleアカウントに紐づく非公開領域)にのみ保存されます。
  • これらの情報は開発者を含む第三者から参照できません。スプレッドシートを他者と共有しても共有されません。
  • アドオンをアンインストールし、保存済みの接続情報を削除したい場合は、サポートまでご連絡ください。削除手順をご案内します。

収集しないもの

  • Salesforceのデータ(取得されたレポートの内容は利用者のシートにのみ書き込まれます)
  • 利用状況の分析データ(アクセス解析・トラッキングは行っていません)
  • 個人情報(氏名・メールアドレス等を収集する仕組みはありません)

Google APIの利用について

本アドオンによるGoogle APIから受け取った情報の利用は、Google API Services User Data Policy(限定使用の要件を含む)に準拠します。
